## 当前实现盘点

- 原有用户可见下载名由前端 `useRecordExport` 的 `a.download` 设置为 `report.document_number + '.docx'`。
- 后端 `record_generator_service` 另使用“清洗文号 + 时间戳 + `.docx`”生成服务端临时文件名；前端下载属性会覆盖该内部临时名，因此本次继续将用户可见文件名的唯一规则集中在共享前端工具中，不改变后端临时路径。
- 页面原本没有自定义文件名开关，也没有独立文件名状态。
- 日期时间字段只有三处：`introduction.entrust_time` 为纯日期，`introduction.inspection_time_range` 为分钟精度范围，`attachments.burning_date` 为纯日期。此前均使用普通文本 `EditableField`。
- 项目未发现可复用的日期选择器封装；本次使用现有 Ant Design `Input` 的原生 `date` 与 `datetime-local` 控件，不引入新依赖。控件值在前端立即转换回现有中文接口格式。
