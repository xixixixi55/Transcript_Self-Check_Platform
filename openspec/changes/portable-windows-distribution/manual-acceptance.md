## 托盘启动生命周期

- [ ] 在 Windows 10 x64 与 Windows 11 x64 各启动一次候选包，确认启动过程没有命令行窗口或要求一直保留的模态窗口。
- [ ] 确认通知区域显示文枢图标，图标在 100%、125%、150% 显示缩放下轮廓清晰且没有不透明底色。
- [ ] 关闭浏览器窗口后确认文枢后端继续运行；双击托盘图标和右键“打开文枢”均能重新打开当前应用。
- [ ] 右键选择“退出文枢”，确认托盘图标消失、后端结束且再次双击 `文枢.exe` 可以正常启动。
- [ ] 运行期间再次双击 `文枢.exe`，确认不会启动第二个后端实例。
- [ ] 通过任务管理器结束后端进程，确认托盘图标自动撤销并显示明确的停止提示。
