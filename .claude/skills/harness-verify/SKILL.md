读取项目根目录的 `.codebuddy/commands/harness/verify.md` 获取详细执行协议，按其步骤执行 `/harness:verify` 的完整流程。

**快速参考**（完整步骤见命令文件）：
1. 运行综合验证（架构检查 + 类型检查 + 构建）
2. 运行自动化测试
3. 运行文档一致性检查
4. 报告通过/失败

**与 `/harness:review` 的区别**：
- verify = 工程验证（自动化脚本，检查结构正确性）
- review = 需求验证（Agent 对照 spec 场景，检查语义覆盖）

建议同时运行两者以获得完整验证。
