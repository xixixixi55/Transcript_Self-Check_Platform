# Proposal: 电子数据检查笔录自动生成

## Why

民警使用美亚手机大师（FL-901）对涉案手机取证后，得到一份结构化 HTML 取证报告。之后需要将报告中的数据手工填入标准格式的电子数据检查笔录（.docx），过程繁琐、易出错、格式不统一。

需要一个工具：**上传 HTML 取证报告 → 自动解析提取数据 → Web 预览完整笔录 → 民警在线审核修改任一内容 → 导出 .docx**。

## What

### Capabilities

1. **CAP-001: HTML 报告上传与解析** — 上传美亚手机大师 HTML 报告目录，自动解析案件信息、设备详情、取证工具版本、提取数据分类统计
2. **CAP-002: 笔录 Web 预览** — 解析后渲染完整的检查笔录预览（绪论 9 项 + 检查 4 项 + 附件清单），自动填入提取到的数据，缺失字段留空待填
3. **CAP-003: 全文在线编辑** — 民警可在预览页面上**直接修改任意内容**（每个章节每个字段都可编辑），不用跳转到其他页面
4. **CAP-004: 导出 .docx** — 确认无误后点击导出，系统调用 officecli 生成标准格式 .docx 并下载
5. **CAP-005: 硬件设备管理** — 设置页面可添加/编辑/删除取证硬件设备（如 FL-901），生成笔录时下拉选择

### Non-Goals

- 本次不实现 Word 在线编辑器（用 Web 表单编辑 + officecli 导出）
- 本次不实现批量上传和批量生成
- 本次不实现用户登录和权限管理
- 本次不实现 Celery 异步任务（先用同步方式）
- 本次不实现其余 5 类文书
