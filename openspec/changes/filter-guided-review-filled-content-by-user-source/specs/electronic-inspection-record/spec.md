## MODIFIED Requirements

### Requirement: REQ-GUIDED-REVIEW-SHELL — 默认对话式审核外壳

#### Scenario: “已填内容”只展示用户主动形成的内容

- **WHEN** 用户在案件审核页打开“已填内容与待办”面板
- **THEN** “已填内容”只展示当前最终值明确由用户输入、选择、修改、确认或上传形成的可回访事项
- **AND** 报告识别、系统默认或系统计算且未经用户修改的内容不得出现在“已填内容”中
- **AND** 用户修改系统识别或系统带入的字段后，系统展示该字段的用户最终值，不展示已经被覆盖的旧值
- **AND** Word 内容预览继续按既有规则展示报告草稿的全部最终生效内容，不受“已填内容”来源过滤影响
